# KV260 PYNQ package

This directory is self-contained. Copy the entire directory to the KV260 and
run:

```bash
cd PYNQ
python3 pynq.py
```

The `pynq.py` compatibility entry point loads `KV260.bit` and `KV260.hwh`, initializes the packaged SDF and
triangle data, streams the default 1920x1080 ray frame, shades FPGA hits with
the same method as `csrc` `HostRenderer`, and continuously sends the shared
RGB buffer to DisplayPort. `mem/pynq_render_data.bin` is the PS-side render
sidecar generated by `make sim`; it must match the deployed
`mem/triangle_ddr.bin`. Use `--no-display` for headless verification. Hit
shading is vectorized in chunks; tune
`--shade-chunk-pixels` if the board needs a smaller temporary-memory peak.

The board must have PYNQ installed with `pynq`, NumPy, and Pillow available,
and the CMA pool must provide buffers inside the DMA DDR windows exported in
`KV260.hwh`.  The current hardware maps both `ray_dma` and `tri_datamover`
through PS HP0 low DDR (`0x00000000..0x7fffffff`), so buffers allocated above
that range cannot be reached by PL DMA and the script will stop before running.
Use `--width` and `--height` for a smaller smoke test before a full frame.

## Runtime layout

The implementation follows a package layout so hardware access, rendering,
and orchestration can evolve independently:

```text
pynq.py                 compatibility entry point
sdf_rt/config.py        RTL addresses, DMA registers, and defaults
sdf_rt/formats.py       FP9/memory parsers and AXI stream codecs
sdf_rt/camera.py        camera rays, tiled raster order, and rectangular ROI
sdf_rt/shading.py       HostRenderer-compatible CPU shading
sdf_rt/dma.py           Overlay, MMIO, CMA buffers, SDF setup, and AXI DMA
sdf_rt/pipeline.py      double-buffered DMA/render worker pipeline
sdf_rt/io.py            ray prepacking and image/result output
sdf_rt/app.py           frame lifecycle, ROI reuse, and performance stats
sdf_rt/cli.py           command-line parser and validation
```

Deploy the complete `PYNQ/` directory. Copying `pynq.py` without `sdf_rt/`
is not sufficient.
